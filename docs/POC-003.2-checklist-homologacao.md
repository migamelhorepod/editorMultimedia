## Invariantes
- Não há botão para cancelar importação biblioteca/timeline; a remoção é ação posterior.
- Não modificar originais ou projetos por causa da limpeza de resultados parciais.
- Acesso já aberto deve cessar após falha por término do Job/handles. RevokeTask isoladamente não fecha handles.
- Uma importação normal não possui timeout de 30 segundos; este limite vale só para tratamento de falhas.
- O componente MediaWorkerAdmission continua fail-closed até integração segura.
- Testes unitários novos não são prova de UI real nem de ausência de workers órfãos.
